# 📖 HTMLScope — HTML 標註閱讀器

單一 HTML 檔的「閱讀器＋標註器＋輕量協作工具」。開啟任何 HTML 文件即可劃螢光筆、寫對話串註解、直接修改內文，並打包成零安裝的「含標記版」在團隊間來回傳遞、自動合併。

**為什麼存在**：AI 讓產出 HTML 報告變得零成本，但 HTML 缺乏 PDF 那種「註解存在檔案裡」的原生機制 — 市面工具都要裝擴充功能＋註冊帳號＋雲端同步。HTMLScope 把標註引擎直接塞進檔案裡解決這件事。

## 使用

**線上直接試用:https://sjjcoder.github.io/htmlscope/**（不必下載；一樣是在你自己的瀏覽器裡跑，沒有任何資料上傳）

或雙擊 `htmlscope.html` → 把任何 HTML 檔拖進去（或用「✍ 直接貼上文字」貼 Word／Google 文件的內容）→ 選取文字開始標註。

工具首頁的說明採**分層設計**：最上方「30 秒看懂」兩張純 CSS 示意圖不用點開就看得到（`.ug-*` class，見架構要點），下面三個摺疊區塊依需求展開 —— 📖 基本操作／⚙️ 進階功能／🔧 疑難與細節。**這是實測結果驅動的設計：7/7 受測者都反映原本的單一長條列「看兩段就放棄」，所以核心用法必須零點擊可見、技術細節必須收進最後一層。**

## 功能總覽

| 面向 | 功能 |
|---|---|
| 開檔 | 拖曳／選檔開任何 HTML，或 **✍ 直接貼上文字**（從 Word／Google 文件／PDF 複製即可，不必轉檔；貼 HTML 原始碼會自動偵測並照原樣顯示）；另附「我沒有 HTML 檔?」轉檔說明 |
| 閱讀 | 最近開啟快取、載入時自動拆除 script（安全）、深淺色自動切換 |
| 語言 | 繁中／英文雙語（🌐 切換，自動偵測瀏覽器語言），字典跟著含標記版帶走 — 收件人依自己的偏好顯示 |
| 標記 | 四色螢光筆（🎨 預設集:一般審閱／AI 報告審閱／自訂，語言感知、隨檔案傳遞）、對話串註解（署名＋時間）、✓解決、草稿防丟、註解視窗可拖曳 |
| 直接改字 | ✏️ 直接修改文件內文（contentEditable），立即生效、不留標註，改動跟著含標記版帶走 |
| 追蹤 | 未解決計數徽章、關鍵字搜尋、顏色／未解決篩選、點擊跳轉 |
| 流通 | ⬇ 含標記版（文件＋標記＋引擎打包，收件人零安裝、可續標回傳自動合併）、列印附註解對照表 |
| 匯出 | 📤 選單:🖨 列印／存成 PDF（整份文件＋標記編號＋文末註解對照表，走瀏覽器列印對話框）／📄 一頁標註清單（HTML，只有標註）／Markdown 待辦清單／JSON 結構化資料（含 anchoring 上下文）。**非技術使用者看得懂的排序與白話副標是實測結果驅動的** |
| AI 迴圈 | 🤖 選單：**產生修改指令**(未解決標註一鍵聚合成結構化 prompt——原文＋脈絡＋分類＋留言＋建議修改＋指示，複製／下載 .md 回餵 Claude／GPT／Cursor)／**比較版本**(跟基準版本比對，看這一輪實際改了什麼) |
| 提議修改 | 每則標註可帶「💡 提議改成…」（像 Word 的建議修訂：不會馬上生效）：可接受（套用進文件，留稽核紀錄且可還原）／移除；進 prompt 時輸出成確定性「提議改成」指令讓 AI 照抄。**圖示刻意用 💡 而非鉛筆，與「✏️ 直接改字」區隔**（實測 4/7 使用者因兩者都用鉛筆而混淆） |
| 版本比對 | 🔍 比較版本：自動記錄基準版本(首次開啟＋每次產生修改指令時)，之後跟目前版本比對，紅刪除線／綠底線標出差異，可更新基準。零依賴字詞級 Myers diff，過大時退回前後綴粗略比對 |

## 架構要點（維護前必讀）

- **單檔三段式**：閱讀器外殼（開檔/最近清單）＋ 標註引擎（`ENGINE` 函式 + `ENGINE_CSS` + `ENGINE_UI` 字串）＋ 注入機制。引擎以 `(ENGINE.toString())()` 形式注入文件 iframe，也烙進「含標記版」輸出檔
- **按鈕分工（避免重複）**：頂欄只放導覽（🏠 回列表、📂 開啟）＋全域語言；所有文件/標註動作只在面板（面板須自給自足，才能在獨立開啟的含標記版運作）。面板的 🌐 靠 `window.parent.__scopeSetLang` 偵測是否在閱讀器內，在則隱藏、獨立開啟才顯示。**新增動作鈕請只加在面板,不要在頂欄複製**
- **⚠️ 新增彈出視窗/選單時務必檢查調色盤變數清單**：`--as`/`--atx`/`--aln`… 這組 CSS 變數只定義在特定選擇器上（`#annoBar,#annoPop,#annoPanel,#annoToggle,#annoStaticApp,#annoPromptOverlay,#annoDiffOverlay,.anno-menu`），漏加新元件的 ID 會導致該元件背景/文字色變透明看不清楚（v2.3、v3.1 都踩過這個坑）——新增任何頂層彈出元件,第一件事就是把它的 ID 加進這兩條規則(含深色模式那條)
- **含標記版輸出** = 清理後的文件 + 引擎 + `script#annoPreset`（JSON，v2 格式 `{legend, annotations}`）+ 烙印 mark 元素 + `#annoStaticApp` 靜態對照表（無 JS 環境如手機預覽用；正常瀏覽器開啟時引擎會移除它接管互動）
- **標記定位**：引文（quote）為主、前後 32 字上下文（`prefix`/`suffix`）消歧、位置就近決勝 — 對齊 W3C TextQuoteSelector；舊標註無上下文則退回位置就近並於定位後就地補上。精確失敗 → **模糊救回**（`fuzzyLocate`：上下文重定位 → 局部/全文 bigram Dice 滑窗），命中標為 `approx`（虛線+≈,清單琥珀色）。仍找不到才列為 orphan（留言不丟）
- **儲存**：localStorage，key 用「文件標題」的 hash（檔名會因 `_標記版` 後綴改變，標題不變）；刪除用墓碑（`key::del`）防止合併時復活
- **合併**：留言層級（同一標註的 thread 逐則合併，以留言 id 去重）— 來回傳遞不會蓋掉任何人的話
- **i18n**：外殼與引擎各持一份字典（`SHELL_I18N`／引擎內 `I18N`），共用 localStorage key `annoReader::lang`；介面文字一律由 `applyShellLang()`／`applyI18n()` 填入，**不要**寫死在 HTML 或 `ENGINE_UI` 字串裡。新增介面文字時兩種語言都要補
- **彈出視窗共用外觀**：`.anno-modal-ov`(遮罩+置中)／`.anno-modal-bx`(卡片)＋`.pm-head`/`.pm-hint`/`.pm-foot`，🤖修改指令與🔍比較版本兩個 modal 共用同一套；新增 modal 沿用這組 class，不要重寫外觀
- **版本比對(diff)**：`saveBaseline()`/`loadBaseline()` 存取 `KEY::baseline`(全文快照+時間戳,純本機、不烙進含標記版)；`diffWords()` 走自寫字詞級 Myers diff(`myersDiffCapped`+`backtrackDiff`),差異或文件過大時退回 `prefixSuffixDiff`(共同前綴/後綴+中段整塊替換,O(N+M) 保底,避免卡頓)
- **使用說明的示意圖用純 HTML/CSS(`.ug-*`),不要用真實截圖** — UI 仍在快速迭代,螢幕截圖會不斷過期、需要重截；CSS 示意圖改文字幾個字就跟上,不會過期。兩份圖各自寫在 `SHELL_I18N.zh.tips` / `.en.tips` 字串裡(非即時雙語切換,兩語言各自完整一份)

## 已知雷

1. **文件自帶舊版標註 CSS 會打架** — `cleanDocument` 已拆除（regex 要迴圈跑：相鄰規則共用 `}` 邊界，單次 replace 會隔條漏刪）
2. **舊版《分配書 v6.3》內嵌單-note 格式標註** — 閱讀器開啟時自動搬移其 localStorage（key `agenthub-anno-v6.3`）
3. **同標題不同文件會共用標記庫**（title-hash 索引的代價，換取來回傳遞的連續性）
4. 相對路徑圖片不顯示（iframe 無 base URL）；文件快取上限 1.5MB

## 開發規則

- **版本號在工具列左上**，每次改版 +0.1 並更新 `CHANGELOG.md` — 使用者曾多次因開到舊副本誤報 bug，**先對版本再診斷**
- 驗證用本機 HTTP server（`python -m http.server --bind 127.0.0.1`）＋瀏覽器實測；注意測試環境的截圖與 `innerWidth` 可能故障，用 `getBoundingClientRect`／計算樣式驗證
