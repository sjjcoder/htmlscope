The AI review loop · advanced

Turn your notes into the AI's next prompt.

A report the AI wrote gets reviewed by a human — then goes back to the AI to be fixed. HTMLScope closes that loop: one click turns every open annotation into a structured revision prompt, complete with the exact quote and its surrounding context, ready to paste into Claude, GPT or Cursor.

1

Mark what's wrong

Switch the four colors to the AI-review preset — fact error, unsourced, verified, tone.

2

One click → a prompt

🤖 aggregates every note, quote and comment — with context — into one instruction. Copy it, or download .md.

3

Paste back, regenerate

The AI locates each passage by its quoted context and returns a revised draft. Review again — the loop tightens each round.

What's inside

Small file. Full review workflow.

A

Highlights with presets

Four colors, one click to switch between a general-review preset and an AI-review one (fact error, unsourced, verified, tone) — or rename them yourself.

B

Threaded comments

Every message carries a name and a timestamp. Reply back and forth, mark threads resolved.

C

Edit the text itself

Fix a typo or reword a line in place — edits travel inside the annotated copy too.

D

Safe by default

Loaded documents are stripped of scripts before they render. Open untrusted HTML without a second thought.

E

Reads on a phone

Preview windows in chat and mail can't run scripts — so the highlights and a static comment table are baked in, visible anyway.

F

Export anywhere

A one-page HTML report, a Markdown checklist for issues/Notion/PRs, or structured JSON for scripts and LLMs. Plus print with numbered notes.
